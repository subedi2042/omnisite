# OmniSite Visual Theme Catalog

Professional theme directions and ready-to-copy instructions for Google Antigravity.

> Use one theme per customer website. Keep the OmniSite dashboard on its own neutral product design system. Do not mix customer-theme colors into builder controls.

## 1. Sanctuary Modern

**Best for:** Churches and faith communities  
**Character:** Welcoming, peaceful, established  
**Typography:** Libre Baskerville + Inter  
**Page rhythm:** Editorial hero, service times, welcome, messages, events, ministries  
**Avoid:** Religious clip art, crowded announcements, gold used everywhere

```text
Semantic color tokens:
- Deep Navy: #17243A
- Warm Ivory: #FAF7F1
- Muted Gold: #B68A45
- Soft Sage: #718174
- Slate: #667085
```

## 2. Community Light

**Character:** Bright, open, hopeful  
**Typography:** Manrope + Source Sans 3

Semantic color tokens:
